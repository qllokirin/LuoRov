# BPM-TTR / BPM-TTS 深度传感器（RS485）调试指南

> 参考文档：
> - `3794166056BPM-TTR（485输出）样本.pdf`
> - `3794122470RS485 通讯协议说明 V2.3.pdf`

本传感器是基于 316L 不锈钢波纹膜片隔离充油式的硅压阻数字压力传感器，内置温度补偿与非线性修正电路，直接通过 **RS485（标准 MODBUS-RTU 协议）** 输出数字信号。建议先使用 **USB 转 RS485 模块 + 电脑串口调试助手（或 Modbus Poll）** 完成联调，再接入主控系统。

---

## 1. 硬件接线与供电参数

### 1.1 线序定义

> 注：样本 PDF 第 2 页接线表部分文字因字体颜色设置在部分阅读器中不可见，提取底层文本后的准确定义如下：

| 导线颜色 | 信号名称 | 接线说明 |
| :---: | :---: | :--- |
| **红线** | 电源正 (`VCC`) | 接 **10V ~ 32V DC** 直流电源正极（常用 12V 或 24V） |
| **蓝线** | 电源负 (`GND`) | 接直流电源负极（建议与 RS485 收发器的 `GND` 共地） |
| **黄线** | `485A` | 接 RS485 模块的 `A+` / `T/R+` |
| **白线** | `485B` | 接 RS485 模块的 `B-` / `T/R-` |

### 1.2 关键电气与环境指标

- **供电电压**：`10 ~ 32V DC`（**严禁仅使用 USB 的 5V 供电**，电压不足会导致传感器无法启动或通讯无响应）
- **上电响应时间**：`≤ 100ms`（上升到 90% FS）
- **内部采样频率**：`10 kHz`
- **精度与温补**：`0.1% FS`（10kPa 量程为 `0.5% FS`），宽温区补偿 `-10℃ ~ 70℃`（`≤100kPa` 量程为 `0 ~ 60℃`）
- **压力过载能力**：`≤ 1.5 倍` 满量程

## 2. 串口与 Modbus 通讯配置

### 2.1 默认串口参数

| 参数名称 | 出厂默认值 | 可配置范围 |
| :--- | :---: | :--- |
| **通讯协议** | `MODBUS-RTU` | 支持功能码：`03H`、`04H`、`06H`、`10H`（十进制 16） |
| **从站地址** | `1` (`0x01`) | `1 ~ 247` |
| **波特率** | `9600` | `1200`, `2400`, `4800`, `9600`, `19200` |
| **数据位** | `8` | 固定 `8` 位 |
| **奇偶校验** | 无校验 (`None`) | 无校验 (`0`)、奇校验 (`1`)、偶校验 (`2`) |
| **停止位** | `1` | 固定 `1` 位 |

### 2.2 数据编码格式（大端序 Big-Endian）

- **`float`（单精度浮点数，占 2 个寄存器 / 4 字节）**：标准 IEEE-754 格式，传输顺序为 **`ABCD`（高字节在前，高字在前）**。
  - 示例：`100.0` 对应十六进制 `0x42C80000`，报文传输顺序为 `42 C8 00 00`。
- **`unsigned short`（无符号短整型，占 1 个寄存器 / 2 字节）**：高字节在前。
  - 示例：`4660`（`0x1234`），报文传输顺序为 `12 34`。
- **CRC 校验**：标准 `CRC-16/MODBUS`（低字节在前，高字节在后）。

## 4. 串口调试助手快速联调步骤（HEX 报文速查）

打开串口助手，选择 `9600, 8, N, 1`，勾选 **HEX 发送** 和 **HEX 显示**，按顺序发送以下指令（均按默认从站地址 `0x01` 计算好 CRC）：

### 步骤 1：核对当前单位与量程
1. **读取主变量单位（`0x000A`）**
   - 发送：`01 03 00 0A 00 01 A4 08`
   - 预期返回示例：`01 03 02 00 0C B8 41`（`00 0C` = `12`，代表当前单位为 `kPa`）
2. **同时读取量程上限与下限（`0x0200` 连读 4 个寄存器）**
   - 发送：`01 03 02 00 00 04 45 B1`
   - 解析：返回数据段共 8 字节，前 4 字节为量程上限（`float`），后 4 字节为量程下限（`float`）。

### 步骤 2：读取实时主变量与温度
1. **读取主变量值（`0x0000`）**
   - 发送（功能码 03）：`01 03 00 00 00 02 C4 0B`
   - 备用（功能码 04）：`01 04 00 00 00 02 71 CB`
   - 解析：例如返回 `01 03 04 42 C8 00 00 6F B5`，数据字节 `42 C8 00 00` 按 IEEE-754 大端浮点数转换即为 `100.0`。
2. **读取实时温度值（`0x0006`）**
   - 发送：`01 03 00 06 00 02 24 0A`
   - 验证：常温下返回 `20.0 ~ 30.0 ℃` 左右，可用手握住传感器外壳观察温度缓慢上升以验证链路正常。
3. **一次性连读全部动态参数（`0x0000 ~ 0x000A`，共 11 个寄存器 / 22 字节数据）**
   - 发送：`01 03 00 00 00 0B 04 0D`
   - 解析：可在一个通讯周期内同时拿到主变量、百分比、电流、温度、毫伏值与单位，适合主控循环采集。

## 5. 水下机器人（ROV）深度解算与校准方案

传感器硬件可能是**表压型（G）**或**绝压/密封压型（S）**（空气中绝压型读数约为 `101.3 kPa`，表压型接近 `0 kPa`）。在 ROV 系统中推荐以下两种用法：

### 方案一：传感器输出 `kPa` + 主控软件扣零换算（推荐）

保持传感器固定输出压力单位 `kPa`，由上位机/主控程序管理水面零点与水体密度，灵活性和可靠性最高：

1. **将传感器单位固定设为 `kPa`（向 `0x0208` 写 `12`）**：
   - 发送：`01 06 02 08 00 0C 09 B5`
2. **下水前零点采集**：ROV 下水前在空气中（或刚贴近水面时）连续读取 10~20 次压力值取平均，记为水面大气压基准 $P_0$（单位：`kPa`）。
3. **实时水深换算公式**：
   $$h = \frac{(P - P_0) \times 1000}{\rho \cdot g}$$
   - **淡水环境**：取 $\rho \approx 998\text{ kg/m}^3,\ g = 9.80665\text{ m/s}^2$（每米水深约对应 `9.787 kPa`）
   - **海水环境**：取 $\rho \approx 1025\text{ kg/m}^3,\ g = 9.80665\text{ m/s}^2$（每米水深约对应 `10.052 kPa`）
4. **内部阻尼建议**：若用于 ROV 定深 PID 控制，建议检查并将 `0x0206` 阻尼时间设为 `0.0`（减小传感器内部平滑带来的相位滞后），在主控端自行做高频采样 + 一阶低通或卡尔曼滤波。

### 方案二：使用传感器内置深度单位 + 硬件调零

若希望直接从 `0x0000` 读出以米为单位的液位深度：

1. **修改主变量单位为 `m`（代码 `45`）或 `mH2O`（代码 `240`）**：
   - 设为 `m`：`01 06 02 08 00 2D C9 AD`
   - 设为 `mH2O`：`01 06 02 08 00 F0 09 F4`
2. **入水前在空气中发送主变量清零指令（向 `0x0300` 写入 `1`）**：
   - 发送：`01 06 03 00 00 01 48 4E`

## 6. Python 快速联调测试脚本

安装依赖 `pip install pyserial` 后，修改串口号 `PORT` 即可在电脑上直接读取压力、温度与水深：

```python
import struct
import time
import serial

PORT = "COM3"       # 修改为实际 USB-RS485 串口号
BAUDRATE = 9600
SLAVE_ID = 0x01
RHO_WATER = 998.0   # 淡水 998.0 kg/m^3，海水可改为 1025.0 kg/m^3
G = 9.80665


def calc_crc16(data: bytes) -> bytes:
    crc = 0xFFFF
    for b in data:
        crc ^= b
        for _ in range(8):
            crc = (crc >> 1) ^ 0xA001 if (crc & 1) else (crc >> 1)
    return bytes([crc & 0xFF, (crc >> 8) & 0xFF])


def read_registers(ser: serial.Serial, start_addr: int, count: int) -> bytes:
    req = struct.pack(">BBHH", SLAVE_ID, 0x03, start_addr, count)
    req += calc_crc16(req)
    ser.reset_input_buffer()
    ser.write(req)
    expected_len = 3 + count * 2 + 2
    resp = ser.read(expected_len)
    if len(resp) != expected_len:
        raise TimeoutError(f"串口响应超时或长度不完整: 收到 {len(resp)} 字节 ({resp.hex(' ')})")
    if calc_crc16(resp[:-2]) != resp[-2:]:
        raise ValueError(f"CRC 校验失败: {resp.hex(' ')}")
    return resp[3:-2]


def main():
    with serial.Serial(PORT, BAUDRATE, bytesize=8, parity="N", stopbits=1, timeout=0.5) as ser:
        # 读取当前单位代码 (0x000A)
        unit_code = struct.unpack(">H", read_registers(ser, 0x000A, 1))[0]
        print(f"当前主变量单位代码: {unit_code} (12=kPa, 45=m, 240=mH2O)")

        # 采集空气零点基准 (假设单位为 kPa)
        p0 = struct.unpack(">f", read_registers(ser, 0x0000, 2))[0]
        print(f"初始零点基准 P0 = {p0:.3f}")

        while True:
            # 连读 0x0000 ~ 0x0007 (主变量、百分比、电流、温度，共 8 个寄存器)
            payload = read_registers(ser, 0x0000, 8)
            pv, pct, curr_ma, temp_c = struct.unpack(">ffff", payload)
            depth_m = (pv - p0) * 1000.0 / (RHO_WATER * G)
            print(f"主变量: {pv:8.3f} | 温度: {temp_c:5.2f} ℃ | 相对水深(按kPa换算): {depth_m:6.3f} m")
            time.sleep(0.2)


if __name__ == "__main__":
    main()
```

## 7. 常见故障排查清单

1. **发送指令后完全无返回**：
   - 用万用表测量传感器红、蓝线两端电压是否达到 **`10V ~ 32V`**（确认未误接 5V）。
   - 尝试将黄线（`485A`）和白线（`485B`）对调（部分 USB-485 转换器丝印极性定义相反）。
   - 若传感器曾被修改过参数，尝试切换波特率（`9600` / `19200` / `4800` / `2400` / `1200`）或轮询地址 `1 ~ 247`。
2. **有返回报文但解析出的浮点数极其巨大或为 `NaN`**：
   - 检查高低字节序：本传感器为大端 `ABCD` 顺序。在 STM32 / x86（小端架构）中不能直接将接收字节数组强转为 `float*`，必须先做字节翻转或使用大端解包（如 Python `>f`）。
3. **协议文档中的地址细节差异说明**：
   - 协议文档 `3.2` 节报文中举例用了地址 `0x0404`，属于通讯格式示意；实际寄存器地址请以第 4 节寄存器表（主变量 `0x0000`）为准。若个别定制固件读取 `0x0000` 无效，可尝试发送示例报文 `01 04 04 04 00 02 31 3A` 验证。
4. **物理防护注意事项**：
   - 前端金属波纹膜片极薄且内部充硅油，**切勿用手指、螺丝刀或硬物按压感压膜片**，否则会导致永久零点漂移或膜片损坏；测试压力变化时请直接将传感器浸入水桶或量筒中观察读数变化（每下潜 `10 cm` 压力约上升 `0.98 kPa`）。
